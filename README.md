# 写り込み顔モザイク

写真を読み込み、**残したい範囲**を指やカーソルで囲むと、**それ以外に写った顔へ自動でモザイク**をかけ、**別ファイル**として出力するWebアプリです。

- スマホ・タブレット・PC対応（タッチ／マウス）。2本指・ホイールで拡大移動
- 写真は端末内だけで処理（外部送信なし）。ライブラリ・検出モデルも同梱し、CDN不要でオフライン可（PWA）
- 元の写真は変更せず `○○_mosaic.jpg` を出力（EXIF・位置情報は除去）
- ビルド不要の静的サイト。**すべてのファイルが同じ階層（サブフォルダなし）**

## ファイル構成（すべて同じディレクトリ）
| ファイル | 役割 |
|---|---|
| `index.html` | 画面（CSP・メタ情報を含む） |
| `style.css` | **配布いただいたスタイルシート（無改変）** |
| `app.css` | このアプリ固有の部品（キャンバス、ツール、モーダル等）。`style.css` の色変数を利用 |
| `app.js` / `geometry.js` / `imageinfo.js` / `integrity.js` / `guard.js` | 本体／幾何・判定／画像ファイル検査／完全性検証／起動前の防御 |
| `face-api.js`, `ssd_mobilenetv1_model*` | 顔検出エンジンとモデル（同梱・MIT） |
| `sw.js`, `manifest.webmanifest`, `icon*.png/svg`, `apple-touch-icon.png` | オフライン対応・ホーム画面追加用 |
| `CHECKSUMS.sha256`, `_headers`, `SECURITY.md`, `CHANGELOG.md` | 改ざん検知用ハッシュ／ヘッダー設定（任意）／セキュリティ説明／変更履歴 |
| `*.test.mjs`, `package.json` | テスト（`npm test`） |

見た目を変えたいときは `style.css` を差し替えるだけです（`app.css` は `--uguisu` `--line` などの変数名を使っています）。

## 使い方
1. 「写真を選ぶ」（ドラッグ＆ドロップ・貼り付けも可）。顔は自動検出されます
2. 「四角」または「手描き」で、残したい人を囲む。囲んだ範囲の外の顔にモザイクがかかります（範囲指定なし＝全員にモザイク）
3. **自動で見つからなかった顔は「手動追加」**: ツールの「手動追加」を選び、顔をドラッグで囲むとモザイクを追加できます（何個でも・上限300件）。追加した枠は「手動追加」を選んでタップすると削除、「戻す」で復元、設定の「手動の枠を全消去」で一括削除。手動の枠は「残す範囲」に関係なく、保存時に必ずモザイクが適用され、再検出しても消えません
4. 「モザイクなし」を押すと、全ての顔のモザイクを外した元の画像を表示します。もう一度押すとモザイク表示に戻ります（四角・手描きを押しても編集に戻ります）。**保存は常にモザイク適用後**です
5. 小さい顔が多い写真は 設定→「高精度」→「この設定で再検出」
6. 「保存して確認」→ 仕上がりを確認 → 共有（写真に保存）／ダウンロード

拡大・移動: 2本指（スマホ）／ホイール（PC）で拡大縮小、2本指ドラッグ／`Space`+ドラッグ／マウス中ボタンで移動（「モザイクなし」表示中は1本指・ドラッグでも移動）、「全体」で全体表示。
PCショートカット: `Ctrl/⌘+Z` 戻す、`+` `-` `0` 拡大縮小/全体、`1` 四角、`2` 手描き、`3` モザイクなし、`4` 手動追加

## GitHub Pages で公開
1. リポジトリを作成し、**このフォルダのファイルをすべて（フォルダ分けせず）アップロード**（スマホのブラウザからでも可）
2. Settings → Pages → Branch を `main` / `(root)` にして Save、「Enforce HTTPS」を有効に
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で利用（スマホのホーム画面に追加も可）

※ `index.html` をダブルクリックして開く（`file://`）と、ブラウザの制限でアプリは起動しません（その場合は画面に案内が出ます）。手元で試すなら `python3 -m http.server` → http://localhost:8000
※ 更新したときは `sw.js` の `VERSION` を上げてください（古いキャッシュが残らないように）。

## 仕組み・制約
- 顔検出: [face-api (vladmandic)](https://github.com/vladmandic/face-api) の SSD MobileNet v1。画像全体＋タイル分割（標準=1024px、高精度=さらに640px）で検出し、重複を統合
- 顔枠の50%以上が「残す範囲」に入っていれば残す。判定できない顔は「モザイク」側（安全側）。プレビューと書き出しは同じモザイク格子
- **検出は100%ではありません。** 横顔・極小・強い逆光・マスク等で漏れます。漏れた顔は「手動追加」で隠せます。公開前に必ず目視確認してください
- 総画素が1600万を超える写真は縮小して処理（iOSのcanvas上限対策）。出力はJPEG（品質0.93）
- 初回のみ約7MBを読み込みます（以後キャッシュ）
